# 🎓 BoardCast — Браузерная P2P-трансляция доски для студентов

> Одностраничное веб-приложение (SPA), решающее извечную проблему: вместо того чтобы каждую минуту фоткать доску с первого ряда и заливать в чат группы, ты просто ставишь телефон на парту — и одногруппники смотрят доску вживую со своих смартфонов с зумом, стоп-кадром и фильтрами.

---

## ⚡ Как это запустить прямо сейчас

Поскольку для доступа к камере телефона (`getUserMedia`) мобильные браузеры (Chrome, Safari) **требуют HTTPS** (или `localhost`), есть 3 самых быстрых способа запуска:

### Способ 1. Загрузить на бесплатный хостинг за 1 минуту (Рекомендуется для пар)
Просто закинь файлы `index.html`, `style.css`, `app.js` на любой статический хостинг с бесплатным HTTPS:
- **GitHub Pages** (создать репозиторий -> включить Pages в настройках)
- **Vercel** (`npx vercel` в этой папке)
- **Netlify Drop** (перетащить папку мышкой на netlify.com)
- **Cloudflare Pages**

*После этого у тебя будет ссылка вида `https://твое-имя.github.io/boardcast`, которую можно открывать на парах с любого телефона.*

---

### Способ 2. Локальный запуск на компьютере/ноутбуке
Если тестируешь на ноутбуке:

```bash
# Через Python:
python -m http.server 3000

# Или через Node.js:
npx serve .
```
Открой в браузере: `http://localhost:3000`

---

### Способ 3. Запуск по локальному Wi-Fi с пробросом HTTPS (через ngrok / localtunnel)
Если сервер запущен на ноутбуке, а подключиться нужно со смартфонов:

```bash
npx localtunnel --port 3000
# или
ngrok http 3000
```
Полученную `https://...` ссылку можно сразу открывать на смартфонах.

---

## 🛠 Технологический стек
- **WebRTC & DataChannel:** библиотека **PeerJS** для прямой P2P-передачи видеопотока и данных без выделенного медиасервера.
- **Интерфейс:** Чистый HTML5, Tailwind CSS (CDN), кастомный CSS (глубокий OLED-стиль, анимации, адаптивные фильтры).
- **Жесты:** Мультитач Pinch-to-zoom (до 10x), свободное панорамирование (Drag/Pan) по доске.
- **API браузера:** Screen Wake Lock API (телефон не гаснет), ImageCapture API, MediaDevices & Constraints API.
